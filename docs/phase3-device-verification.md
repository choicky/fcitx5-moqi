# Phase 3 实机回归：v0.1.3-moqi.1 操作与记录表

> 目的：用正式发布包（`org.fcitx.fcitx5.android.moqi`）完成 Phase 3 最后一项"Android 实机回归"，
> 同时覆盖发布线冒烟与"墨奇表经 addon config component 分发"的实机确认。
> 结果回来前，Phase 3 保持 IN PROGRESS（不得标 COMPLETE）。

## 准备

1. 下载 [v0.1.3-moqi.1](https://github.com/choicky/fcitx5-android/releases/tag/v0.1.3-moqi.1) 的 arm64-v8a APK，允许"安装未知应用"后安装。
   - 包名 `.moqi`，可与官方 Fcitx5 **共存**；同一条发布线之间可直接覆盖升级。
   - 早前的测试包（`.debug`）与它不互通，可保留也可卸载。
2. 系统设置 → 语言和输入法 → 启用新装的 Fcitx5（release 名称为 `Fcitx5`，debug 为 `Fcitx5 (Debug)`）。
3. 在新应用内添加「拼音」输入法。

## 回归步骤与期望（含参考码值）

参考码值（固定码表）：西 = `ak`、安 = `bn`、你 = `rx`、啊 = `kk`。

| # | 操作 | 期望 |
|---|---|---|
| 1 | 拼音设置页查看 `Auxiliary Filter` | 三选一：`Disabled` / `Stroke` / `MoQi`，默认 `Stroke` |
| 2 | 选 `MoQi` → 系统设置里对应用「强行停止」→ 重开设置页 | 仍为 `MoQi`（持久化） |
| 3 | 输入 `xian` → 按反引号 **`** → 输入 `a`、`k` | 辅助栏显示过滤状态；**西安** 仍在候选 |
| 4 | 继续输入 `z`（即 `ak` 后第 3 个字母） | 辅码 buffer 仍为 `ak`（两位码上限），候选不变 |
| 5 | 连按 3 次 Backspace | 逐级退码并最终退出筛选模式；候选栏不再显示「墨奇」动作 |
| 6 | 输入 `xian` → **`** → 输入 `zz` | 无匹配 → **西安** 被过滤掉（列表可能为空） |
| 7 | 按 Escape | 退出筛选，**西安** 恢复 |
| 8 | 输入 `xi''an` → **`** → `ak` → 选中 **西** → 继续输入 `men` | composition 未提交；**安** 仍在候选（selection frontier 前进、可继续输入） |
| 9 | 再按 **`** → `bn` → 选中 **安** → 再按 **`** → Escape | **门** 仍在候选（二次/三次进入筛选正常） |
| 10 | 设为 `Stroke` → 输入 `ppp` | 能筛出「彡」（上游笔画行为未回归） |
| 11 | 设为 `Disabled` → 有候选时按 **`** | **不触发筛选**（预期行为：按键按字面处理，会输入一个反引号） |
| 12 | 确认官方 Fcitx5 与新包同时存在 | 两个输入法可分别启用/切换，互不覆盖 |

## 需要留存的证据

```
adb logcat | findstr /i "pinyin moqi Filtering"
```
